# 📊 Customer Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer purchasing behavior to uncover meaningful insights that can help businesses improve decision-making, marketing strategies, and customer engagement.

The analysis is performed using a combination of **Python, SQL, and Power BI**, following a complete end-to-end data analytics workflow.

---

## 🎯 Objectives

* Understand customer purchasing patterns
* Analyze the impact of discounts and promo codes
* Identify key factors influencing customer spending
* Perform category-wise and demographic analysis
* Build an interactive dashboard for business insights

---

## 🗂️ Dataset Description

The dataset contains customer transaction and behavioral data with features such as:

* Customer ID
* Age, Gender
* Category of purchase
* Purchase Amount
* Discount Applied (Yes/No)
* Promo Code Used (Yes/No)
* Review Rating
* Purchase Frequency

> 📌 Note: The dataset is used for analysis purposes and may be synthetic or sample data.

---

## 🛠️ Tools & Technologies Used

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **SQL (MySQL)**
* **Power BI**
* **Jupyter Notebook**

---

## 🔄 Project Workflow

### 1️⃣ Data Collection & Loading

* Imported dataset using Pandas
* Connected MySQL with Jupyter Notebook

### 2️⃣ Data Cleaning

* Handled missing values (median imputation by category)
* Removed inconsistencies in categorical data
* Standardized column formats

### 3️⃣ Exploratory Data Analysis (EDA)

* Distribution of purchase amounts
* Category-wise sales analysis
* Gender-based comparison
* Discount vs non-discount behavior

### 4️⃣ SQL Analysis

* Revenue calculation by category and gender
* Discount usage percentage
* Customer segmentation queries
* Aggregations using GROUP BY

### 5️⃣ Data Visualization (Power BI)

* Built interactive dashboard
* KPIs: Total Revenue, Avg Purchase, Discount Rate
* Filters: Category, Gender, Age Group
* Visual insights for business decisions

---

## 📊 Key Insights

* Customers using promo codes tend to have higher engagement
* Discounts significantly influence purchase behavior
* Certain categories contribute more to overall revenue
* Customer ratings vary across categories
